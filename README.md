## Design
- **Tier:** 1 (Clean Slate)
- **Fonts:** Six Caps (ultra-condensed display caps) + Roboto (body) — Google Fonts
- **Palette:** electric blue, charcoal, high-vis yellow
- Single-file, static `index.html`. Self-hosted images under `assets/`.

## Notes
- **Demo** — carries a `noindex` robots meta (see removal comment in `<head>`) so it stays out of search until the client goes live.
- No contact forms, no prices, no invented facts (no emails, licenses, or founding years).
- Testimonials are real Google review quotes, attributed by first name + last initial.
- `Electrician` JSON-LD, semantic HTML, alt text, reduced-motion-aware reveals, lazy-loaded images.
